# Frenik Mangukiya | Portfolio

A premium, production-ready, and fully responsive personal portfolio website built with **React** and **Tailwind CSS**.

## ✨ Features

- **Modern UI/UX**: Dark mode aesthetic with vibrant indigo and cyan accents.
- **Responsive Design**: Fluid layouts that look great on any device, from mobile to ultra-wide monitors.
- **Interactive Elements**: Smooth hover transitions and glowing effects using Tailwind CSS.
- **Performance Optimized**: Built with Vite for fast loading and optimal asset delivery.
- **Lucide Icons**: High-quality visual anchors for skills, links, and navigation.

## 🛠️ Tech Stack

- **Framework**: React.js
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Vite
- **Deployment**: GitHub Pages (Recommended)

## 🚀 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Frenik06/Portfolio.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run in development mode**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```

## 👨‍💻 Sections

- **Hero**: Introduction and social links.
- **Technical Skills**: Interactive badges for languages and tools.
- **Experience**: Vertical timeline of professional work.
- **Projects**: Dynamic grid with tech stack tags.
- **Education**: Compact academic history.
